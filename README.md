# forest-map

森林計画図（1頁目）に、森林簿（2頁目以降）に記載された施業番号（林班57 小班ル・オ・ワ・カ）の区画を赤で囲んで表示するツールと成果物。

## 成果物
- `output/森林簿_地番位置図.pdf` : 1頁目＝区画を赤枠＋薄赤塗りで表示した図面、2〜4頁＝森林簿原本
- `output/森林簿_地番位置図_1頁目.png` : 1頁目の画像版

## スクリプト（実行順）
1. `scripts/annotate.py` : 番号ラベルの位置定義（`LOTS`）。ラベルを赤枠で囲う旧版の出力も作れる。
2. `scripts/segment.py` : 図面画像（`map_full.png`）から区画線を抽出し、各番号ラベルの周囲から塗りつぶして区画を求める。
   区画線は「直線的な線（直線構造要素によるオープニングで残る画素）＋太線（林班界・道路）」とし、曲線＝等高線は除外する（方式B）。
   小さな区画など方式Bで辺が落ちる場合は、濃い連続線をすべて使う方式Aの結果と比べ、森林簿の面積に合う方を採用する。
   図面の格子線・数字は事前に除去。途切れ等は `scripts/segment_config.json` の補助線（barriers）・消去矩形（erasers_A）・
   手動区画（manual）で補正。出力: `masks.npz`, `regions.json`
3. `scripts/render_regions.py 入力.pdf 出力.pdf 出力1頁目.png` : 区画の輪郭を赤で描き、凡例を付けてPDFを組み立てる。

## 注意
- オ小班の 2・5・11 は図面上に番号の表示が確認できなかったため未表示。
- ワ1は図面上端で切れているため北側が不完全。ル20・ワ6・カ2は面積が森林簿と合わないため概略。オ15・オ18・ル21・カ4は手動で区画を指定。

## 位置合わせ（ジオリファレンス）
- `scripts/georef_export.py 出力先` : 図面の500m座標格子（旧日本測地系 平面直角座標VI系, EPSG:30166）から縮尺・回転を、
  惣社水分神社（地理院地図上の位置）から平行移動を求め、平行移動を500m格子にスナップして確定する（スナップ残差 約30m以内）。
- 出力（`output/geo/`）:
  - `林班57_区画.kml` : 区画ポリゴン。Googleマイマップ / Google Earth に読み込める
  - `林班57_区画.geojson` : 同内容のGeoJSON（QGIS等）
  - `森林計画図_重ね合わせ.kmz` : 赤枠付き図面画像をGoogle Earthに重ねるためのGroundOverlay
  - `林班57_区画位置図.html` : ブラウザで開くと地理院地図・航空写真・OSMの上に区画を表示
  - `georef.json` : 変換パラメータ、`位置合わせ確認_*.png` : 地理院地図との重ね合わせ確認画像

## 手書き修正版（現行）
利用者が赤ペンで修正した図面の写真 `input/森林簿_手書き.jpg` を正として区画を作り直した。
- `scripts/segment_hand.py` : 写真をSIFT特徴点で元図面に位置合わせ（`hand_to_map_homography.npy`）し、赤インクをHSVで抽出。
  赤線（＋林道の太線）を境界として各番号の周囲から塗りつぶし、区画を求める。補正は `segment_hand_config.json`
  （seeds: 種点、manual: 手動区画、red_only: 赤線のみを境界にする区画、barriers: 補助線）。
- 以降の `render_regions.py`・`georef_export.py` は共通。現在の `output/` はこの手書き版の結果。
- 森林簿の面積と大きく異なる区画（ル15・ル19・ル20・ワ6・カ1〜カ4）は手書きの赤線どおりとし、凡例に※印で注記。
