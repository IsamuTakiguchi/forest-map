# forest-map

森林計画図（1頁目）に、森林簿（2頁目以降）に記載された施業番号（林班57 小班ル・オ・ワ・カ）の位置を赤枠で表示するツールと成果物。

- `scripts/annotate.py` : 注記スクリプト（`python3 scripts/annotate.py 入力.pdf 出力.pdf 出力1頁目.png`）
- `output/森林簿_地番位置図.pdf` : 成果物（1頁目＝赤枠付き図面、2〜4頁＝森林簿原本）
- `output/森林簿_地番位置図_1頁目.png` : 1頁目の画像版

赤枠は番号ラベルの位置を示すもので、各区画の範囲は図面の区画線を参照のこと。
オ小班の 2・5・11 は図面上に番号の表示が確認できなかったため未表示。
